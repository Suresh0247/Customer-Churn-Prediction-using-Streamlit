# Customer Churn Prediction App

This is a simple Machine Learning project built using Python and Streamlit.

The app predicts whether a customer is likely to leave the company based on:
- Years with company
- Monthly charges
- Number of support calls



## Technologies Used

- Python
- Pandas
- Scikit-learn
- Streamlit



## Machine Learning Model

The project uses:
- Logistic Regression



## Features

- Customer churn prediction
- Interactive Streamlit interface
- Model accuracy evaluation
- Real-time prediction
